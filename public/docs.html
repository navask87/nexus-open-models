Nexus Open Models API

curl https://YOUR-PROJECT.vercel.app/v1/models

Image

curl -s https://YOUR-PROJECT.vercel.app/v1/images/generations \
  -H 'Content-Type: application/json' \
  -d '{"prompt":"watercolor radio telescope at dusk"}'
